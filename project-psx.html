Project

📈 PSX Risk Scorer

A free risk-scoring tool for Pakistan Stock Exchange stocks that generates a full narrative report where every sentence is traceable to a number it computed, not an LLM's guess.

Python Streamlit Web Scraping Plotly SQLite Cache Zero API Keys
The problem

Retail investors on the Pakistan Stock Exchange don't have anything like a standardised risk score. Financial data is scattered across a live pricing terminal, a separate data portal for quarterly figures, and PDF annual reports, with no single source giving the full picture.

The approach

Scrapes and cross-verifies company financials from multiple official sources, catching real bugs along the way (one source reports figures in thousands, silently understating results 1000x if not rescaled). Scores each company across Valuation, Financial Health, and Growth pillars using industrial or bank-specific templates, then generates a narrative report where every sentence is assembled directly from a number the scoring engine already computed.

The result

A live Streamlit app that builds a full report, gauge score, five-year trend, quarterly financials, catalysts, risks, and linked source documents, in under 20 seconds, entirely free to run: no LLM, no API key, no subscription.

Screenshots

All screenshots below are of a live-generated report for FFC (Fauji Fertilizer Company), pulled fresh from PSX data sources at the time they were taken.

The headline score
A 0 to 100 gauge score, key stats (price, 52-week range, market cap, dividend yield), and a one-line "situation" summary generated from a rule-based pattern match over the pillar scores, not AI-generated prose.
Price history and score breakdown
A five-year price chart sourced from PSX's own data portal, alongside the weighted breakdown across the three scoring pillars and a per-metric detail tab.
Why each metric matters
Every pillar explains its own reasoning in plain language before showing the numbers, here: why EV/EBITDA and dividend yield pull risk in opposite directions, followed by a five-year EPS/DPS/ROE trend.
Quarterly financials
Quarterly sales, profit after tax, and EPS, a data source most tools skip since psxterminal.com only exposes annual figures. Scraped from PSX's own quarterly disclosure tables instead.
Catalysts, risks, and sources
Catalysts and risks generated from the scored metrics and recent news, a bottom-line summary, and direct links to the underlying audited filings so the real source document is always one click away.
